# Detection-Driven Infrared-Visible Image Fusion Using CBAM and U-Net Architectures

This repository contains the implementation codes for the study titled “Detection-Driven Infrared-Visible Image Fusion Using CBAM and U-Net Architectures.”

The study includes infrared-visible image fusion experiments using classical fusion methods, CBAM-based fusion models, CBAM-U-Net architecture, and YOLOv8-based object detection evaluation.

The implementation codes, experimental scripts, and usage instructions will be uploaded and organized in this repository.
